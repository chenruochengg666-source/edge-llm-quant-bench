# 噪声对照实验操作说明

## 一、实验要回答的问题

论文在 ARC-Easy 上观察到：Qwen0.5B 的 Q4_K_M（67.94%）与 Q2_K（64.01%）**高于** FP16（53.04%）。

两种解释：

| 解释 | 含义 | 若成立，论文怎么写 |
|---|---|---|
| **(A) 量化特有** | 量化噪声以某种方式"正则化"了模型 | 反升是量化的真实效应，需进一步分析机理 |
| **(B) 统计效应** | 任何扰动都会改变预测分布，在标签分布不均的题集上偶然表现为准确率上升 | **反升是分布扰动的统计伪影，不是能力提升** |

**导师的建议是先排除 (B)。**

## 二、为什么用 temperature 近似噪声

严格做法是给 logits 注入高斯噪声，但 llama.cpp 没有现成接口（要么改源码，要么重搭 Python 环境）。

**temperature 的作用机制：**

$$p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

$T>0$ 时，原本被压制的小概率选项被抬升，采样引入随机性 —— **效果上等价于对 logits 施加与温度相关的扰动**。

**虽然不等幅，但方向一致：都是"给决策过程加噪"。**

**如果温度扰动也能产生"反升"，就说明反升不依赖量化这一特定噪声源。**

## 三、实验设计

| 项 | 设置 |
|---|---|
| **模型** | `qwen0.5b-base.gguf`（FP16，反升现象的来源模型） |
| **题库** | ARC-Easy（反升在此观察到；2376 题，默认取 500 题子集） |
| **温度梯度** | **0.0（基线）/ 0.3 / 0.5 / 0.8 / 1.0** |
| **随机种子** | 42 / 43 / 44（T>0 有随机性，多次取均值） |
| **采样参数** | top_p=1，其余同主实验 |

**温度点的用意：**

| 温度 | 含义 |
|---|---|
| **0.0** | 确定性贪心，等价于主实验的 FP16 基线 |
| 0.3 | 轻微扰动 |
| 0.5 | 中等扰动 |
| 0.8 | 较强扰动 |
| 1.0 | 强扰动（接近原始分布采样） |

## 四、运行

**当前默认配置（v2 加强版）**：9 个温度 × 3 个种子 × 全量 2376 题，约 5~6 小时。

```bash
# 正式版（默认配置，挂机跑）
python run_noise_control.py
```

**可选规模（按需缩短）**：

```bash
# 快速验证流程（200 题，2 个温度，约 8 分钟）
python run_noise_control.py --temps 0,1.0 --seeds 42 --subset 200

# 中等规模（1000 题，约 2 小时）
python run_noise_control.py --subset 1000

# 稀疏温度点（5 个温度，约 3 小时）
python run_noise_control.py --temps 0,0.1,0.3,0.5,1.0
```

**温度梯度的用意**：

| 温度 | 覆盖区间 | 目的 |
|---|---|---|
| 0.00 | 无扰动 | 基线（对应主实验 FP16 的 53.04%） |
| **0.05 / 0.10 / 0.20** | **弱扰动** | **量化噪声可能落在这一区间，反升最可能出现** |
| 0.30 / 0.40 / 0.50 | 中等扰动 | 观察性能开始下降的位置 |
| 0.70 / 1.00 | 强扰动 | 确认上限（验证版已见 T=1.0 降至 44.5%） |

## 五、结果判读（脚本会自动给出）

### 结果 A：T>0 时准确率上升

**脚本输出：**
```
✅ 温度 [0.5, 0.8] 下准确率高于基线 → 分布扰动可复现'反升'，支持统计效应解释
```

**论文写法：**
> 为区分"量化正则化"与"分布扰动的统计效应"，本文对 Qwen0.5B 的 FP16 模型在相同题集上施加采样温度扰动作为噪声对照。结果显示，温度 0.5 与 0.8 下的准确率（XX% 与 XX%）同样高于确定性基线（53.04%）。这表明，**准确率反升并非量化特有的正则化效应，而是分布扰动在浅层题集上引起的统计现象**——扰动改变了模型的预测分布，在标签分布不均匀的题集上偶然提高了命中率。据此，本文将反升现象的解释由"量化正则化"修正为"分布扰动的统计伪影"。

**价值：把推测变成有实验支撑的结论，且更诚实。**

### 结果 B：T>0 时准确率单调下降

**脚本输出：**
```
所有 T>0 均不高于基线 → 反升更可能是量化特有，而非噪声统计效应
```

**论文写法：**
> 温度扰动对照显示，随温度升高准确率单调下降（0.3/0.5/0.8/1.0 分别为 XX/XX/XX/XX%），均低于确定性基线（53.04%）。这说明单纯的采样随机化不能复现"反升"，该现象更可能与量化对权重分布的具体改变有关，而非一般性的噪声扰动。后续将通过权重层的扰动实验进一步定位。

**价值：说明反升是量化特有，为后续机理研究留出接口。**

### 结果 C：无明显趋势

**可能原因：温度扰动与量化噪声的强度不匹配。**

**论文写法**：如实报告，说明该近似方法的局限，并列为后续工作。
